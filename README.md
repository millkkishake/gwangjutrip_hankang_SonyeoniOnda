# 소년이 온다 · 광주 문예기행 사이트

## 파일 구조
- index.html      처음 화면
- comic.html      인물별 세로 웹툰 (CHAPTERS 데이터를 고치면 내용이 바뀜)
- places.html     방문 장소 선택 → 사진·설명 (PLACES 데이터를 고치면 내용이 바뀜)
- assets/style.css  공통 디자인
- images/         장소 사진 폴더 (dochung.jpg, square.jpg, sangmugwan.jpg, jeonil.jpg,
                  archives.jpg, freedom.jpg, oldcemetery.jpg, cemetery.jpg)

## GitHub Pages로 올리기
1. github.com 에서 New repository → 이름 예: gwangju-trip → Public → Create
2. "uploading an existing file" 클릭 → 이 폴더 안의 파일과 폴더를 통째로 끌어다 놓기 → Commit
3. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save
4. 1~2분 뒤 https://아이디.github.io/gwangju-trip/ 에서 열림

## 사진 넣기
images 폴더에 위 이름대로 사진을 넣으면 자동으로 보입니다.
직접 찍은 사진이나 공공누리 제1유형 사진을 쓰고, places.html의 credit 칸에 출처를 적어 주세요.
